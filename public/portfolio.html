ACS Call Transcription & Time-Entry Automation

A three-stage Azure Functions pipeline that automates the full lifecycle of a support call — answers incoming Azure Communication Services calls, plays consent audio, records the conversation, and stores WAV chunks to Blob Storage. A second Function App transcribes the recordings via Azure Speech batch transcription and sends the transcript to Azure OpenAI for structured analysis, extracting the engineer name, full transcript, and a professional time-entry summary. A third app resolves the engineer to an Autotask resource, locates their active ticket, and posts the generated note automatically. Built with Python, Event Grid, Azure OpenAI, and full idempotency tracking end-to-end.

Azure Functions Azure OpenAI Azure Speech Python Autotask
🔒 Private Client Tool
