## Flagship engineering work

### E3 IT Services — Cloud Integration Engineering

<img src="https://e3itservices.com/wp-content/uploads/2021/02/e3-logo-fulltext.svg" alt="E3 IT Services" width="150">

I own four private production platforms that automate day-to-day service delivery. The systems are listed here at a portfolio level; internal applications, customer data, and source code remain private.

#### ACS Call Automation and Live Engineer Assistance

An Azure communications platform covering consent, recording, voicemail failover, tiered engineer routing, and live call events over WebSockets. During calls, engineers receive relevant customer and support context from connected internal resources. Azure Speech and Azure OpenAI produce transcripts, structured analysis, and documentation connected to Autotask workflows.

#### Unified Backup Monitoring

A serverless monitoring platform covering approximately **525 backup assets** across Datto BCDR, Datto Endpoint Backup, SaaS Protection, and Axcient x360Recover. It normalizes vendor data, detects failures and stale states, preserves historical records, supports live engineering triage, and automates tickets and exception reports.

#### Unified Network Monitoring and Automation

A multi-tenant platform that consolidates UniFi, SonicWall, and Cisco Meraki telemetry. It monitors site and device health, correlates firmware with CVE and EPSS intelligence, and turns actionable findings into automated operational workflows.

#### On-Call Engineer Routing and Ticket Intelligence

An Azure automation system that identifies the active on-call engineer and delivers urgent tickets with priority, affected systems, history, and relevant context—helping engineers respond faster with better information.

### Funari Public Adjusters — AI Estimate Comparison Platform

<img src="https://dantecorso.com/images/funari-logo.png" alt="Funari Public Adjusters" width="96">

A secure client platform that compares an insurance carrier's estimate with the public adjuster's estimate. Google Vision OCR extracts both PDFs, Gemini analyzes differences in scope, line items, quantities, pricing, and totals, and the application returns structured discrepancy data.

The system maps its findings back onto the carrier's original PDF and creates an annotated document with affected items highlighted and notes explaining what requires review or revision. It also produces an AI-generated synopsis and PDF/Excel exports for negotiation, documentation, and client reporting.

`React` `Firebase` `Cloud Functions` `Google Vision OCR` `Gemini AI`

> Private client platform. No application link or internal data is published.

### Emberknot — A Private Connection App for Two

<a href="https://emberknot.com"><img src="https://dantecorso.com/images/emberknot-logo.svg" alt="Emberknot" width="82"></a>

Emberknot is a personal product built around a simple idea: staying close should not require another conversation to keep up with. It is a private space for two people to exchange small gestures, share everyday moments, and preserve important dates and memories. It is not a dating service or a public social network.

The public website and interactive previews are live; the mobile application is currently in development.
